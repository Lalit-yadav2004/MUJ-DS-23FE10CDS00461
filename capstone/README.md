## Executive Summary
CodePulse AI is a state-of-the-art NLP & Multi-Agent LLM system designed to automate software vulnerability triage, eliminate false positives through adversarial critic reflection, and synthesize validated security patches with regression tests for Python, C, and C++ codebases.

### Architecture Highlights
- **AST Semantic Preprocessor**: Reduces token overhead by 65%.
- **Stage 1 (Hunter)**: Chain-of-Thought taint tracking to CWE Taxonomy.
- **Stage 2 (Auditor Critic)**: Devil's advocate proof-of-defense cross-examination.
- **Stage 3 (Patch Synthesizer)**: Unified diffs & regression unit tests.
- **Stage 4 (Deterministic Validator)**: 6 static checks ensuring zero regressions.
